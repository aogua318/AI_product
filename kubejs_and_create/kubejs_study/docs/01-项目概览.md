# 01 - 项目概览

## 这个仓库里有什么

```
kubejs_and_create/
├── kubejs/          # KubeJS 本体的源代码（一个独立的 git 仓库）
├── KubeJS-Create/   # KubeJS 的 Create 附属模组源代码（也是独立的 git 仓库）
└── docs/            # 本学习文档
```

这是两个 GitHub 开源项目放在一起方便对照学习，它们不是同一个仓库，各自有自己的 `.git`。

## 两个项目分别是什么

### kubejs（KubeJS 本体）

- **作用**：让玩家/服主用 **JavaScript 脚本**修改 Minecraft 游戏——改配方、加物品方块、写事件逻辑、改世界生成等等，而不用写 Java、不用编译模组。
- 脚本放在游戏实例目录的 `kubejs/` 文件夹里（比如 `kubejs/server_scripts/`、`kubejs/startup_scripts/`），改完 `/reload` 就能生效。
- 官网/文档：<https://kubejs.com>
- 协议：LGPLv3

### KubeJS-Create（附属模组）

- **作用**：让 KubeJS 脚本能操作 **Create（机械动力）** 模组——写 Create 的各种机器配方（破碎、混合、压实、序装配列……）、自定义喷嘴行为、锅炉加热器等。
- 它是"附属（addon）"关系：KubeJS 是平台，KubeJS-Create 往平台上注册 Create 的内容。
- 附属文档：<https://kubejs.com/wiki/addons/create>

## 版本信息（来自 gradle.properties）

| 项目 | Minecraft | 说明 |
|------|-----------|------|
| kubejs | 26.1.2 | NeoForge 版（README 里提到 `kubejs-neoforge`） |
| KubeJS-Create | 1.21.1 | mod_version 为 `2101.3.1`（2101 就是 1.21.01 的意思） |

> 注意：两个仓库针对的 MC 版本不一样，说明 kubejs 这个 checkout 是更新的开发分支，KubeJS-Create 稍旧。看源码时以"理解设计思想"为主，别纠结版本差异。

## 源码位置速查

- kubejs 主代码：`kubejs/src/main/java/dev/latvian/mods/kubejs/`，按功能分包（block / item / recipe / event / script ...）
- KubeJS-Create 主代码：`KubeJS-Create/src/main/java/dev/latvian/mods/kubejs/create/`，只有十几个文件，适合入门阅读
- Create 的配方"模式（schema）"定义：`KubeJS-Create/src/main/resources/data/create/kubejs/recipe_schema/*.json`
