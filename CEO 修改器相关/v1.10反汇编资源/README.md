## 与 v1.02 的差异（反汇编层面的关键情报）

1. **重新编译链接**：代码规模相当（.text 0x401000–0x4A2000，640KB），但布局完全重排：
   - v1.02：3 个节区（.text 内混用尾部 BSS）
   - v1.10：4 个节区（.text / .idata / .rdata / **.data 4.4MB 巨型 BSS**）
2. **地址整体后移**，且不同模块位移不一致（见下"模块边界"），**静态偏移不能平移复用**。
3. **玩法代码被改写**：v1.02 修改器的 10 个注入钩点中 9 个的原始指令序列在 v1.10 中已不存在。
4. **资源包完全相同**：9 个 APKG 与 v1.02 逐字节一致（MD5 相同），故 `05_资源解包/` 直接复用 v1.02 的解包成果，未重复解包。

## 函数作用说明的来源与可信度

各模块 `_模块函数清单.md` 的"作用说明"列有三种依据：

- **人工标注**（56 个）：来自 v1.02 分析中经反编译确认的函数作用，通过三种方法重定位到 v1.10：
  - `字节N`：v1.02 函数体前 N 字节在 v1.10 中唯一命中（最可靠）
  - `头字节`：函数前 32 字节完全一致
  - `助记符`：指令助记符序列相似度匹配（附相似度数值）
  并用**资源字符串交叉验证**（如描述提到 `factinf_mine.fce`，则该函数应引用该串）定级为 高/中/低
- **推断**（86 个）：由函数引用的界面 `.fce` / 数据 `.csv` / 资源串与 Win32 API 自动推断
- **未标注**（2525 个）：多为 CRT/库函数与短小工具函数，附"被 N 处调用"提示，结合伪源码阅读

## 复现方式

全部脚本在 `03_分析数据/脚本/`：

| 脚本 | 作用 |
|---|---|
| `export_data.py` | 在 IDA 中导出函数/字符串/交叉引用/调用图/导入表 |
| `export_apis.py` | 导出函数→Win32 API 引用 |
| `bulk_decompile.py` + `run_bulk.sh` | 分批把全部函数反编译为伪 C 源码（自动跳过崩溃函数） |
| `relocate_known.py` | 把 v1.02 已确认函数重定位到 v1.10（字节/头字节/助记符三级匹配） |
| `validate_known.py` | 用字符串证据交叉验证重定位结果并分级 |
| `gen_inventory.py` | 生成带作用说明的各模块函数清单 |
