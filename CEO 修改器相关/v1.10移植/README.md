# 创业王修改器 v1.10 移植包

将 v1.02 修改器（`..\创业王v1.02.exe`）适配到 **1.10 版游戏**（`D:\gameapp\Steam\steamapps\common\創業王\CEO.exe`）。

## 使用方法

1. 启动 1.10 版游戏，进入存档；
2. 运行 `python loader_v110.py`（它会自动启动 v1.02 修改器、等待壳解压、在内存中完成全部适配补丁；已运行则直接附加）；
3. 正常使用修改器。可重复运行加载器（幂等）。

> 也可以用 `test_loader.py` 做自检（启动→打补丁→回读验证→退出）。

## 1.10 关键地址对照表（v1.02 → v1.10）

| 项目 | v1.02 | v1.10 | 验证方式 |
|---|---|---|---|
| s01 钩子（选中地块类型读取） | 0x409E1B | **0x40A36E** | 原始指令字节 `8A 46 03 5F 3C 02` 全文件唯一命中 |
| Ctrl+C 全局（放置类型） | 0x8BC594 | **0x8D6074** | 访问指令上下文匹配：`mov [0x8BC594],0` → `mov [0x8D6074],0` |
| 数据槽 ×3 | 0x4A7840/48/4C | **0x4F7040/48/4C** | v1.10 .data 尾部 BSS，全镜像 0 引用 |
| 版本门禁串 | "v1.02---" | "1.10---" | 游戏版本字符串 "1.10" @ .rdata 0xA2FB4 |

已匹配的函数锚点（自动匹配 1063/1695 对，例）：0x419400 → 0x418AC0。

## 移植原理

1.10 版游戏是**重新编译链接**的（代码 640KB 与 v1.02 相当但布局完全重排：v1.02 的 ".text+尾部BSS" 变成 ".text + .data 巨型 BSS"，节区 3→5）。因此静态偏移全部失效，移植需要逐点重定位：

- 钩子点：用"脚本 Alt 行的原始指令字节 + 上下文"在 1.10 中匹配；未命中（代码被改）的钩子需在 1.10 反编译中按语义重新定位钩点；
- 数据槽：1.02 槽位是 .text 尾部 BSS 的任意暂存区，1.10 中直接选用 .data 尾部无引用页（0 引用已静态验证）；
- Ctrl 全局：取 v1.02 中访问该全局的指令上下文（通配 4 字节立即数）在 1.10 中匹配，读出新地址；
- 版本门禁：标题匹配串等长替换。

工具链：`match_v110.py`（字节匹配）、`match_functions.py`/`match_mnemonics.py`（函数特征匹配）、`anchor_search.py`（区域偏移锚点）、`export_funcs_feat.py`/`export_mnemonics.py`（IDA 特征导出）。
